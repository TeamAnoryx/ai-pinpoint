# Chrome Web Store listing — AI Pinpoint

## Name
AI Pinpoint

## Summary (≤ 132 characters)
Pin any message in Gemini, ChatGPT, or Claude chats and jump straight back to it. Private, offline, no account.

## Category
Productivity

## Description

Long AI conversations have no way to get back to the message that mattered: the spec you agreed on, the snippet that worked, the constraint you set 50 replies ago. AI Pinpoint adds bookmarks for individual messages.

**Pin and jump**
- Click the pin button on any message, use the right-click menu, or press Alt+Shift+P to pin the last reply.
- Open the sidebar (Alt+Shift+S) and click a pinned card. The conversation scrolls to that message and highlights it.
- This works on very long threads, including messages the site has unloaded from the page.

**Stay organised**
- Rename pins, reorder them by drag or keyboard, and filter them.
- See every chat with pins under "All chats".
- Fully keyboard-accessible; supports reduced motion and right-to-left languages.

**Private by design**
- Everything stays on your device. No account, no servers, no analytics.
- Makes no network requests, and works offline.
- Export your pins to a file or import them back at any time.

Works on gemini.google.com, chatgpt.com, chat.openai.com, and claude.ai.

Not affiliated with Google, OpenAI, or Anthropic.

## Single purpose (store form)
Lets users pin individual messages in AI chat conversations and navigate back to them.

## Permission justifications (store form)
- **storage** — stores the user's pins and settings on the device.
- **contextMenus** — adds "Pin this message" to the right-click menu on supported sites.
- **Host access (gemini.google.com, chatgpt.com, chat.openai.com, claude.ai)** — required to show pin buttons on, and navigate within, conversations on these sites. The extension runs on no other site.

## Data usage (store form)
Does not collect user data. Not sold or transferred to third parties. Not used for purposes unrelated to the single purpose. Not used for creditworthiness or lending.

## Remote code
No. All code is packaged with the extension.
